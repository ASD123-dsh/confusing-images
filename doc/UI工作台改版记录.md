# UI 工作台改版 / v0.8.0

## 2026-10-23 需求与基线

- 用户授权自由设计一版观感更好的 UI，并明确选择同时打包新版 EXE，供手动测试。
- 沿用 Python、Tkinter、Pillow、NumPy 和 PyInstaller，不引入新依赖。
- 修改前备份当前工作副本及两个旧版 EXE：`doc/backups/before-ui-refresh-20261023-140305.zip`，含 39 个文件及 SHA256 清单。
- 基线是已修复连续还原和批量停止统计的 v0.7.1 工作副本，不以 Git HEAD 覆盖此前未提交改动。

## 设计与实现

- 墨蓝品牌顶栏、青绿操作强调色、浅灰背景与白色卡片，更新窗口及 EXE 图标配色。
- 左侧集中放置处理方式、算法、口令和强制手动选项；右侧提供素材入口、路径及操作说明。
- 单图使用等宽双图预览；目录模式为列表分配更多宽度，结果区展示已保存大数字及失败、未处理、未校验数量。
- 固定底部操作栏、百分比和细线进度条，明确区分准备、处理中、完成、停止和操作失败。
- 文件列表使用隔行底色，支持横向滚动、空格勾选；点击行后，底部只读框保留完整相对路径，可移动光标、选中复制。
- 单行勾选只更新当前行，避免每次点击重画整张表。忙碌时统一禁止鼠标、空格与全选改变待处理集合。
- 用网格分配列表剩余高度，避免路径栏和说明被挤出；批量统计随预览高度缩放，修复最小窗口下的裁切。
- 切换操作或算法后清除过期统计面板；上次批量详情继续保留，行为与原版一致。
- 保留 PNG 格式、算法、口令和手动结果校验语义。`core.py`、`batch.py`、`tests/test_batch.py` 与本轮备份逐字节一致。
