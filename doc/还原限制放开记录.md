# 还原限制放开 / v0.5.0

## 2026-10-22 用户确认

1. 选择图片还原时不设限制：不再要求本工具生成或携带还原参数。
2. 放开图片格式白名单和固定像素/边长上限。
3. demo 下两张 JPG 参考图原算法和密钥未知，允许在副本上尝试，但不得把猜测结果当成正确还原。
4. 原图保护和自动重名编号保留；备份、修改、测试并打包新版 EXE。

## 备份与范围

- 修改前备份源码、测试、工具、文档和 v0.4.0 EXE：`doc/backups/before-open-restore-20261022-092242.zip`。

## 行为变化

### 图片读取

- `load_image` 不再按扩展名白名单或 `SUPPORTED_FORMATS` 拒绝，改为按实际安装的 Pillow 解码器识别。
- 读取时临时关闭 Pillow 的 `MAX_IMAGE_PIXELS` 固定阈值（读取结束后恢复），移除自定义 `MAX_PIXELS`/`MAX_DIMENSION`。
- 静态 GIF 及无扩展名但内容为图片的文件现在可读取；动画/多页文件提示先导出单帧。
- 扫描批量目录时，已知扩展名保留（以便把损坏文件计为失败），未知扩展名通过图片头识别。

### 还原

- 有 `confusing-images` 参数且未勾选强制手动：仍按参数自动、严格还原并校验像素（不变）。
- 无参数图片：按当前所选算法和密钥尝试还原，结果标记 `RESTORE_STATUS=unverified`，界面明确显示“未校验”。
- 勾选“强制手动尝试（忽略嵌入参数）”：即使有参数也忽略，按所选算法尝试，同样未校验。
- 空密钥的默认参数在界面上显示：Tomato=`1`、PicEncryptRow=`0.114514`、PicEncryptRowColumn=`0.1145`；字符串算法默认空字符串。
- Sort/Random 的手动还原依赖原格式末行完整列映射，不验证密钥，结果未校验。
- 批量还原时：有参数图片自动校验；无参数图片按当前算法尝试；统计区分“已保存”和“未校验”，批量详情逐条说明。

### 诚实提示

- 未校验结果绝不显示为“像素校验通过”，避免把错误算法/密钥的结果误报为成功。
- 兼容模式按钮文案改为“强制手动尝试（忽略嵌入参数）”，避免继续暗示仍受来源限制。
- 说明中强调：取消限制不等于能恢复任意混淆图；JPEG 压缩、缩放、裁切、水印造成的损失无法补回。
