# 文件列表勾选批量处理 / v0.7.0

## 2026-10-22 用户确认

1. 选择文件夹后自动识别路径下所有图片并列出（递归含子目录）。
2. 列表每行显示文件名 + 相对路径，不读尺寸。
3. 支持逐行勾选和全选，仅处理勾选图片。
4. 输出仍保存到所选目录下 `confusing_images` 子目录，保持相对层级、重名编号、不覆盖原图。
5. 列表放在左侧，替代目录模式下的单图预览；右侧保留结果预览。
6. 备份、修改、测试并打包新版 EXE；不提交或推送 Git。

## 实现

- 新增 `FileListPanel`：左侧可勾选文件列表（ttk.Treeview 三列：勾选标记、文件名、相对路径），支持逐行点击切换、全选/全不选、底部计数。
- 目录模式下隐藏单图预览、显示文件列表；选择单图时切换回单图预览。
- 列表默认全部不勾选；`process_directory` 读取 `checked_files()`，未勾选时提示，勾选后构造文件子集 `replace(plan, files=tuple(selected))` 传给 `run_batch`。
- 仅处理勾选图片，输出、层级、编号、多线程并行等行为与全量批量一致。
- 处理中禁用全选按钮，避免并发修改选择。
